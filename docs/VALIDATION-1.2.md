## 직접 확인한 출력과 수정

실제 Chromium에서 생성한 스크린샷·PNG·PDF를 Actions artifact로 내려받아 확인했습니다. 경찰·소방 휘장에 바깥 SVG 크기 스타일이 적용되어 로고가 크게 튀어나오는 문제를 자식 선택자로 제한해 수정했습니다. 규격 시설 번호를 시설 중심에 표시하고 배치 후 자동 확대를 추가했습니다. 모바일에서 안내 문구 배치를 시작하면 작업 시트가 닫혀 지도와 배치 버튼을 사용할 수 있습니다.

지도 번호의 PDF 글씨를 기존 약 5.7pt에서 A4 가로 약 10pt, A3 가로 약 14pt로 개선했습니다. 용지 선택별로 배치도·시간표 영역을 계산하고 네 가지 A4/A3 세로·가로 설정으로 PDF를 실제 생성해 각각 4페이지와 올바른 용지 크기, 모든 시설·프로그램 설명의 보존을 확인했습니다. 자체 배경을 포함한 PNG는 2400×1425픽셀이며 네이버 타일을 포함하지 않습니다. 안내도는 제목·배치도·시설 안내·프로그램 시간표·상세 설명을 함께 보존합니다.

## 데이터·보안 검증 범위

스키마 이전은 기존 원문과 복구 지점을 같은 IndexedDB 트랜잭션에 저장한 뒤 수행합니다. 잘못된 JSON·좌표·미래 스키마·중복 ID 처리와 파일 왕복, 전체 백업·휴지통·원문 보존을 검사합니다. 200,000개 꼭짓점의 출력 경계 계산도 포함합니다.

브라우저의 기본 `fetch` 수신 객체가 잘못 연결되어 서버 요청 전에 실패하던 문제를 수정하고, 기본 요청 함수의 수신 객체를 검사하는 회귀 테스트를 추가했습니다. 두 기기의 변경·충돌·휴지통·복구는 실제 클라이언트 동기화 로직과 서버 API를 함께 사용합니다. 단위 검사는 fake-indexeddb와 메모리 R2를, 브라우저 검사는 독립 브라우저 컨텍스트와 동일 서버 API의 메모리 R2 어댑터를 사용합니다. 로그인이 없는 API 요청과 잘못된 출처, 다른 소유자의 파일 접근, 조건부 쓰기 충돌을 검사합니다.

비공개 앱의 소유자 전용 호스팅 정책은 유지합니다. 공개 Pages는 이전 데이터 복구·백업 안내만 배포하며 편집기와 지도 SDK를 제공하지 않습니다. 비공개 앱의 Service Worker는 로그인 보호를 위해 앱 셸을 캐시하지 않고 서버 인증을 거칩니다. 열려 있는 편집기의 기기 저장은 오프라인에서도 유지합니다.

## 배포와 외부 검증의 한계

비공개 앱 주소는 https://field-event-map-private.sugaryseed3.chatgpt.site 입니다. 검사를 통과한 소스와 일치하는 Worker를 기존 소유자 전용 정책으로 배포합니다. 장소명 검색은 별도 Naver Developers 검색 API의 서버 비밀 환경변수가 필요하며 주소·좌표 검색은 기존 네이버 지도 설정을 사용합니다.

자동 검증은 화면 크기와 Chromium/WebKit 엔진 검사입니다. 실제 Android/iPhone/iPad 하드웨어, OS 설치·파일 공유 화면, 실제 프린터 및 실제 소유자 로그인 세션의 Naver/R2 호출을 이번 브라우저 자동화로 검증했다는 의미는 아닙니다. 배포 여부는 호스팅의 성공 응답으로 확인합니다. 네이버 지도 타일과 검색 응답을 테스트하거나 캡처하기 위해 우회하지 않습니다.
