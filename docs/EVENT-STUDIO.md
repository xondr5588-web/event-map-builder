# 행사 제작 · 1.2

## 빠르게 행사장 구성하기

1. **만들기 → 행사 빠른 제작**을 엽니다.
2. **지역 축제 기본 구성** 또는 **플리마켓 기본 구성**을 누릅니다. 26개 시설의 미리보기를 확인하고 지도에서 배치합니다. 기본안은 편집 가능한 시작점이며 실제 현장에 맞춰 위치·통로·동선을 확인해야 합니다.
3. **부스·무대 배치**에서 미터 규격, 줄 수·개수, 가로·줄 간격, 회전과 번호 접두사를 입력합니다. 최대 200개를 한 번에 배치하고 한 번의 실행취소로 되돌립니다. 배치를 완료하면 새 시설들이 보이도록 지도를 자동 확대합니다.
4. 시설을 선택하고 끌어 이동합니다. **같은 그룹 선택**으로 함께 이동하거나 **그룹 정렬·회전**으로 선택 중심 회전, 중심 정렬, 균등 간격을 적용합니다. 잠긴 객체는 이동하지 않습니다.
5. **시설 번호·설명·규격 수정**에서 이름·번호·방문객 설명·공개 범위를 편집합니다. 지도 번호와 시설 안내 목록이 연결됩니다. 번호 중복은 차단합니다. 꼭짓점을 직접 바꾸면 자유 규격으로 표시합니다.
6. **안내 문구 추가**를 누르면 모바일 시트가 닫힙니다. 지도를 누르거나 **중심에 붙여넣기**로 문구를 배치하고 속성에서 여러 줄 문구·글자 크기·색상·상자 너비를 바꿉니다.

작은 축척에서는 실제 규격 부스가 작게 보입니다. 충분히 확대하거나 시설 목록에서 선택하세요. 작은 부스의 번호는 겹침을 줄이기 위해 확대했을 때 표시됩니다. 인력·기관 마커는 기존의 자동 가독성 크기와 직접 크기 조절을 유지합니다.

## 프로그램·시간표

**프로그램**에서 날짜·시간·장소·분류·설명·공개 여부를 입력합니다. 시설과 연결한 장소는 시설 이름 변경을 따라갑니다. 프로그램 시작과 종료는 실제 날짜·시간을 검증하며, 자정 이후 종료는 종료일을 지정합니다(최대 31일).

CSV 또는 엑셀에서 복사한 표를 가져올 수 있습니다. UTF-8 CSV/TSV를 사용하세요.

```csv
날짜,시작,종료,프로그램,장소,분류,설명,공개
2026-10-19,10:00,11:00,개막식,메인 무대,공연,환영 공연,예
2026-10-19,11:00,12:00,공예 체험,행사부스 B1,체험,현장 접수,예
```

필수 열은 `날짜, 시작, 종료, 프로그램`. 선택 열은 `종료일, 장소, 분류, 설명, 공개`. 영문 헤더 `date,start,end,title,endDate,venue,category,description,public`도 지원합니다. 모든 행을 검증한 뒤 한 번에 추가하므로 중간 행 오류로 일부만 저장되지 않습니다. 같은 장소의 일정 겹침은 경고하며 병행 행사는 유지합니다. 가져오기는 기존 프로그램에 추가하는 방식입니다. 실행취소로 한 번에 되돌릴 수 있습니다.

## 자체 배경·작업 보기

**배경·보기**에서 권한 있는 PNG/JPEG/WebP를 올리고 실제 너비·높이(m), 회전·불투명도를 조정합니다. 그림은 현재 지도 중심에 배치되며 **그림을 지도 중심으로**로 이동할 수 있습니다. 20MB 이하 파일을 최대 2400픽셀로 줄여 저장합니다. 지도 타일을 추출하거나 캐시하지 않습니다.

전체 운영·방문객 안내·비상 대응 보기를 전환하고 최대 20개 위치를 이름과 함께 저장합니다. 전체 운영계획 집계는 숨김·보기와 관계없이 전체 객체를 기준으로 계산합니다. 시설 삭제 후 연결 일정은 저장해 둔 장소명 또는 장소 미정으로 표시하므로 일정을 확인하세요.

## 출력·공유

**출력**에서 부제·하단 안내·강조색, 용도, 용지(A4/A3 세로·가로)를 선택합니다.

- **종합 안내도**: 배치도, 번호별 시설 설명, 날짜·장소별 시간표와 설명 페이지.
- **운영 배치도**: 배치도와 전체 계획 수량.
- **프로그램 시간표**: 날짜·장소별 시간표. 겹치는 일정은 옆 칸으로 표시하며, 많은 일정은 읽기 쉬운 목록으로 나눕니다.
- **완성 배치도 PNG**: 직접 올린 그림을 포함한 2400×1425 지도 이미지. 네이버 배경지도는 포함하지 않습니다.
- **읽기 전용 안내 파일**: 편집기·SDK·API 식별자 없이 열리는 단독 HTML. 오프라인에서 보거나 인쇄할 수 있습니다.

현재 화면 범위를 고정하거나 전체 시설 맞춤으로 출력 범위를 정합니다. 배치도와 시간표의 출력 영역은 선택한 A4/A3 용지와 세로·가로 방향에 맞춰 조절됩니다. PDF 저장 시 브라우저 인쇄 창에서도 같은 용지를 선택하세요. 네이버 배경지도가 필요한 경우 기존 상단 인쇄 기능을 이용하고 출처 표기를 유지하세요.

**방문객용** 출력에는 내부용 객체, 내부 프로그램, 담당팀·연락처·업무지시·내부 메모를 넣지 않습니다. 주차관리원·안전요원·통제·관계자·운영본부는 기본적으로 내부용입니다. 시설별 공개 범위를 확인하세요. 직접 올린 배경과 직접 적은 안내 문구에 포함된 정보는 그대로 출력됩니다. 운영용 출력은 내부 배포를 전제로 합니다.

## 기기 간 이어쓰기

비공개 앱의 같은 소유자 계정으로 로그인하면 로컬 자동저장 뒤 서버의 프로젝트 파일과 동기화합니다. **프로젝트 → 기기 간 동기화**에서 수동으로 갱신할 수 있습니다. 오프라인·서버 오류 시 기기 저장은 유지되고 연결 후 다시 시도합니다. 동기화 저장소는 공개 버킷 URL을 제공하지 않으며 모든 API 요청은 플랫폼의 로그인 사용자 ID로 분리합니다.

두 기기가 동시에 변경하면 기존 변경을 덮어쓰지 않고 **기기 간 충돌 사본**을 만듭니다. 프로젝트 휴지통·복구도 동기화하며, 서버는 프로젝트당 최근 20개 이전 파일을 보관합니다. 기기별 자동 복구 버전과 JSON 전체 백업은 계속 지원합니다. 동기화 한도는 휴지통 포함 300개 프로젝트, 파일당 8MB입니다. 초과하면 JSON으로 내보내 보관하거나 배경 그림을 줄이세요.

브라우저·설치 앱은 서로 다른 기기 저장소일 수 있습니다. 이전 GitHub Pages의 데이터는 공개 복구 페이지에서 JSON 백업한 후 비공개 앱에 가져옵니다. 새 저장소가 기존 출처의 브라우저 데이터를 직접 읽을 수는 없습니다.

## 서버 운영

- `npm run build:site`: 소유자 전용 정적 자산을 내장한 Worker와 로그인 필수 프로젝트 API를 빌드합니다.
- `.openai/hosting.json`의 기존 Site ID와 `r2: "BUCKET"`을 유지합니다. 호스팅이 저장소를 연결합니다. 수동 API 비밀키를 브라우저에 넣지 마세요.
- 주소·좌표 검색은 기존 방식입니다. **장소명 검색**은 네이버 Developers 검색 API의 `NAVER_SEARCH_CLIENT_ID`, `NAVER_SEARCH_CLIENT_SECRET`을 **서버 런타임 비밀 환경변수**로 지정해야 합니다. Maps 브라우저 Client ID나 Maps Client Secret을 재사용하지 않습니다. 미설정이면 주소 검색은 계속 작동하고 장소명 검색 설정 안내를 표시합니다.
- 네이버 공개 브라우저 식별자는 허용 도메인을 비공개 앱으로 제한합니다. 서버 배포에는 소유자 로그인 경계를 유지하세요. 임의의 다른 호스팅에서 `oai-authenticated-user-id` 헤더를 신뢰해서는 안 됩니다. 직접 호스팅하려면 검증된 로그인 미들웨어가 외부 헤더를 제거하고 사용자 ID를 설정해야 합니다.
