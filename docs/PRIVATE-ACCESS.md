# 비공개 운영 전환

FIELD 편집기는 소유자의 ChatGPT 계정으로 로그인해야 사용할 수 있는 비공개 사이트로 이전합니다.

- 비공개 앱: https://field-event-map-private.sugaryseed3.chatgpt.site
- 기존 GitHub Pages: 기존 브라우저 데이터의 백업과 새 사이트 안내만 제공합니다.
- GitHub 저장소는 소스 관리용입니다. 공개 Pages 산출물에는 지도 편집기·지도 SDK 로더·소유자의 지도 Client ID를 넣지 않습니다.

## 네이버 콘솔에서 마지막으로 할 일

Maps → Application → event-map → 인증 정보 → Web 서비스 URL에서 새 주소 `https://field-event-map-private.sugaryseed3.chatgpt.site`를 추가하세요. 기존 `https://xondr5588-web.github.io`는 삭제합니다. 사용하지 않는 localhost·127.0.0.1 주소도 삭제하세요. 기존 주소를 허용한 채 두면 이미 열린 구버전 앱이나 과거 사본이 계속 호출할 수 있습니다.

Client ID는 브라우저용 공개 식별자입니다. 로그인은 앱 접근을 제한하지만 제3자 API의 과금을 절대적으로 차단하는 보장은 아닙니다. 네이버 콘솔의 **한도 및 알림 설정**에서 실제 사용량에 맞춘 API 한도와 알림도 설정하세요. 새 Client ID를 발급하면 기존 공개 이력의 식별자를 더 이상 사용하지 않을 수 있습니다. Client Secret은 앱에 입력하지 않습니다.

## 기존 프로젝트 옮기기

1. 기존 작업을 저장한 기기와 브라우저에서 GitHub Pages 주소를 엽니다.
2. **이전 작업 전체 백업**으로 JSON을 다운로드합니다. 프로젝트·휴지통·저장 버전·구버전 원문·복구 저널 원문을 보존합니다.
3. 비공개 사이트에 소유자 계정으로 로그인하고 **프로젝트 → 가져오기**를 사용합니다.
4. 작업이 정상적으로 열리는지 확인합니다. 원래 브라우저 저장소는 삭제하지 않습니다.

도메인이 바뀌면 브라우저 저장소도 분리됩니다. 자동으로 서버에 업로드하거나 다른 도메인의 저장소를 읽지 않습니다.

## 접근 제어

Sites 호스팅의 서버 측 소유자 접근 정책으로 HTML과 정적 파일 요청을 보호합니다. 임의의 회원가입이나 다른 ChatGPT 계정의 로그인만으로는 소유자 권한을 얻지 못합니다. 앱의 공개 URL, 소스 코드, 버튼 숨김을 비밀번호처럼 취급하지 않습니다.

비공개 앱은 로그인 보호를 위해 앱 파일을 서비스 워커에서 캐시하지 않습니다. 열려 있는 앱의 로컬 편집·저장은 네트워크 장애에도 유지됩니다. 앱을 완전히 닫고 다시 열 때에는 온라인 로그인 확인이 필요합니다. 프로젝트는 계속 해당 기기의 IndexedDB에 저장됩니다.
