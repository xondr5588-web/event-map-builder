# 지도 심볼 출처

지도용 인력·시설 픽토그램 17종은 FIELD에서 작성한 SVG이며 버튼용 일반 아이콘과 분리되어 있습니다. 총 19종을 40×40 좌표계, 동일한 원형 배경·테두리·기준선, 둥근 선 끝으로 표시합니다. 인력은 같은 머리·몸 비율, 시설은 같은 건물·천막 표현, 출입은 녹색 IN·적색 OUT으로 구분합니다. 응급의료는 차량 대신 의료소, 셔틀 승하차장은 버스 대신 정류장 표식을 사용합니다. 도구 목록·지도·출력 범례는 동일한 원본을 사용합니다. 주차관리원은 주황 반사조끼, 안전요원은 정장·선글라스·이어피스를 착용한 경호형 모습, 안내요원은 보라 조끼, 차량 IN/OUT은 차량과 방향 화살표로 표시합니다. 행사부스는 주황·흰색 천막과 판매·안내 카운터 형태이며, 운영본부와 안내소와 구분됩니다. 기존 `safetyStaff` 종류와 저장된 이름·라벨·배치 정보는 유지한 채 그림만 교체합니다.

경찰부스에는 대한민국 경찰 상징 휘장 원본을 사용합니다.

- 제작: 대한민국 경찰청
- 공식 설명: https://police.go.kr/www/agency/intro/intro02.jsp
- 정부 원본 출처: http://www.law.go.kr/lsBylInfoR.do?bylSeq=5383369&lsiSeq=156186
- 원본 파일·이용조건: https://commons.wikimedia.org/wiki/File:Emblem_of_the_Korean_National_Police_Agency.svg
- 파일: `src/assets/police-emblem.svg` (외부 참조·실행 요소·메타데이터 정리, 형상과 색상 보존)

이 상징은 운영도에서 경찰 협조 지점을 식별하기 위한 표시입니다. 앱 자체가 경찰청의 공식 서비스이거나 후원을 받는다는 표시로 사용하지 않습니다. 대외 출력물은 실제 협의된 경찰 배치와 사용 목적을 확인한 후 사용하세요. 출처 표기와 별도의 표장 사용 조건을 유지해야 합니다.

소방 대기소도 소방차 대신 대한민국 소방 상징을 사용합니다.

- 제작: 대한민국 소방청 (SVG 변환: Lee6597)
- 공식 설명: https://www.nfa.go.kr/nfa/introduce/symbolinfo/symbol/
- 원본 형상 확인: https://imgnews.pstatic.net/image/008/2017/09/25/0003940175_001_20170925120609414.jpg
- SVG 원본·출처·이용조건: https://commons.wikimedia.org/wiki/File:National_Fire_Agency_of_the_Republic_of_Korea_Logo_(vertical).svg
- 파일: `src/assets/fire-emblem.svg` (원본의 심벌 그룹을 추출하고 기관명 조합 부분·메타데이터를 제외, 형상·색상·가로세로 비율 보존)

경찰·소방 상징은 자체 그림으로 임의 재설계하거나 색상을 바꾸지 않습니다. 경찰·소방 협조 지점을 식별하기 위한 도면 표식이며, 앱 자체의 공식 인증이나 소속을 뜻하지 않습니다. 원형 테두리 색상 변경은 기관 휘장 자체에 적용되지 않습니다.
