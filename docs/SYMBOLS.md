# 지도 심볼 출처

지도용 인력·시설 픽토그램은 FIELD에서 작성한 SVG이며 버튼용 일반 아이콘과 분리되어 있습니다. 주차관리원은 주황 반사조끼, 안전요원은 안전모·노랑 조끼, 안내요원은 보라 조끼, 차량 IN/OUT은 차량과 방향 화살표로 표시합니다.

경찰부스에는 대한민국 경찰 상징 휘장 원본을 사용합니다.

- 제작: 대한민국 경찰청
- 공식 설명: https://police.go.kr/www/agency/intro/intro02.jsp
- 정부 원본 출처: http://www.law.go.kr/lsBylInfoR.do?bylSeq=5383369&lsiSeq=156186
- 원본 파일·이용조건: https://commons.wikimedia.org/wiki/File:Emblem_of_the_Korean_National_Police_Agency.svg
- 파일: `src/assets/police-emblem.svg` (외부 참조·실행 요소·메타데이터 정리, 형상과 색상 보존)

이 상징은 운영도에서 경찰 협조 지점을 식별하기 위한 표시입니다. 앱 자체가 경찰청의 공식 서비스이거나 후원을 받는다는 표시로 사용하지 않습니다. 대외 출력물은 실제 협의된 경찰 배치와 사용 목적을 확인한 후 사용하세요. 출처 표기와 별도의 표장 사용 조건을 유지해야 합니다.
