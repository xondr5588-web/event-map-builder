# v10.15 분석 및 1.0 전환

기준 커밋: `e07843d4fd42be7c66de043635b1f9af44727e2b`.

기존 저장소는 96KB의 `index.html` 한 파일로 구성되어 있었다. 네이버 지도·객체 편집·localStorage 버전·출력이 구현되어 있었으나 모바일·프로젝트 관리·자동 테스트·빌드/배포 설정은 없었다.

## 기존 기능의 대응

모든 기존 area kind(parking/event/vip), line kind(vehicle/pedestrian/oneway/cone/tape/block/route), marker kind(parkingStaff/staff/safetyStaff/carIn/carOut/control/vipGate/gateIn/gateOut/stage)를 보존하거나 대응한다. `staff`는 `parkingStaff`로 정규화한다. 기존의 라벨 텍스트/표시/픽셀 오프셋/수동 위치/지리 좌표, 마커 회전은 새 label/rotation 필드로 이전한다.

영역 색상·투명도, 선 두께·색상·방향 반전, 주차장 IN/OUT 빠른 생성, 이름 변경·점 추가·이동, 객체 목록·선택·맞춤, 종류별 레이어, 자동/수동 저장·버전 복구, JSON 가져오기/내보내기, 인쇄용 지도와 PDF를 새 UI에 배치했다.

구버전이 localStorage/JSON에 기록하지 않았던 런타임 전용 값은 복원할 수 없다. 기록되어 있는 알려진 스타일 필드를 읽고, 없는 필드는 종류별 기본값을 적용한다. 해석할 수 없는 원본도 백업에 보관한다.

## 데이터 안전 원칙

1. 원래 localStorage를 삭제하거나 덮어쓰지 않는다.
2. 마이그레이션보다 원문 백업을 먼저 완료한다.
3. 여러 프로젝트/버전을 가져올 때 하나라도 잘못되면 쓰기를 시작하지 않는다.
4. 저장 실패 시 화면의 작업을 유지하고 JSON 백업 경로를 제공한다.
5. 다른 창의 revision을 덮어쓰지 않는다. 충돌/중단 데이터는 별도 사본으로 보존한다.
6. 삭제는 휴지통 또는 Undo로 복구할 수 있게 한다.
7. 지도 서비스 비밀키와 지도 타일을 앱 저장소에 보관하지 않는다.
